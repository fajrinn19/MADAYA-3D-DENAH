# MADAYA 3D DENAH

Denah 3D Kawasan Madaya Sinjai — visualisasi interaktif dalam satu file HTML.

## Cara pakai

- Buka `index.html` langsung di browser (tidak perlu server atau instalasi).
- Atau aktifkan GitHub Pages pada repo ini, lalu akses lewat URL Pages.

File ini berdiri sendiri (HTML + CSS + JS dalam satu berkas).
